## Abstract

Entropic Boundary Cosmology (EBC) is proposed as a formal and simulation-ready framework for modeling internal time as an emergent ordering variable generated by trace-bearing exchange across a boundary between accessible and inaccessible sectors of a closed or effectively closed system. EBC is not presented as a replacement for general relativity, quantum field theory, standard cosmology, or thermodynamics. Its disciplined role is narrower: it is a relational-time and boundary-information model that unifies several established ideas — the problem of time in canonical quantum gravity, Page-Wootters internal-clock mechanisms, thermal-time perspectives, reduced-state entropy, decoherence, and laboratory analogue models based on Bose-Einstein condensates — into a computational architecture for toy universes and future analogue simulations. The framework defines a total system `U` partitioned into a bright sector `B`, a dark sector `D`, and an interface boundary `∂`. The bright sector has access only to a reduced state `rho_B = Tr_D(rho_U)`, whose entropy `S_B` marks local incompleteness. Entropic time `tau_E` is then defined as accumulated boundary entropy-production or information-flux. The central clock equation is `d tau_E / d lambda = Phi_∂ / Phi_0`. The manuscript further distinguishes established physics quantities from framework-specific diagnostics including Fource and Darkness Functional.

## 1. Claim boundary

EBC does not claim that the observable universe is literally a computer simulation. It does not identify its dark sector with physical dark matter or dark energy. It does not replace general relativity, quantum field theory, thermodynamics, or Lambda-CDM cosmology.

The peer-reviewable claim is narrower:

> Once a system is partitioned into accessible and inaccessible sectors, a reduced state and a boundary flux can be defined; if that flux is nonnegative and integrable, it can generate a monotonic internal ordering parameter.

Framework-specific terms such as Fource and Darkness Functional are diagnostics, not established physical observables.

## 2. Primitive definitions

Let `U` denote a closed or effectively closed total system.

```text
U = B ∪ D ∪ ∂
```

where:

- `B` is the bright sector: accessible, observed, measured, recorded, or locally available.
- `D` is the dark sector: inaccessible, ignored, traced out, unresolved, hidden, or complementary relative to `B`.
- `∂` is the boundary/interface through which exchange may occur.

For a quantum model, approximate factorization may be written:

```text
H_U ≈ H_B ⊗ H_D ⊗ H_∂
```

The bright-sector reduced state is:

```text
rho_B = Tr_{D,∂}(rho_U)
```

The bright-sector entropy is:

```text
S_B = -k_B Tr(rho_B log rho_B)
```

This entropy is the local cost of not possessing the whole state.

## 3. Boundary flux and internal entropic time

Let `lambda` be an external, computational, laboratory, or gauge parameter. Let `Phi_∂(lambda)` be a nonnegative boundary flux. A minimal toy definition is:

```text
Phi_∂ = |dS_B/dlambda|
```

A more disciplined model may use entropy production:

```text
Phi_∂ = sigma_∂,    sigma_∂ >= 0
```

A diagnostic model may combine entropy change, mutual information change, particle flux, and energy flux:

```text
Phi_∂ = a|dS_B/dlambda| + b|dS_D/dlambda| + c|dI(B:D)/dlambda| + d|J_N| + e|J_E|
```

with:

```text
I(B:D) = S_B + S_D - S_BD
```

Define internal entropic time:

```text
d tau_E / d lambda = Phi_∂ / Phi_0
```

or:

```text
tau_E(lambda) = tau_E(lambda_0) + ∫[Phi_∂(u)/Phi_0] du
```

If `Phi_∂ > 0`, internal time advances. If `Phi_∂ = 0`, internal entropic time stops relative to this partition.

## 4. Entropic lapse

The entropic lapse is:

```text
N_E(lambda) = d tau_E / d lambda = Phi_∂ / Phi_0
```

An FRW-like bright-sector model may be written as:

```text
ds_E^2 = -c^2 N_E(lambda)^2 d lambda^2 + a(lambda)^2 d Sigma_k^2
```

or:

```text
ds_E^2 = -c^2 d tau_E^2 + a(tau_E)^2 d Sigma_k^2
```

This is a model-space metric for an internally timed bright-sector universe, not a replacement for Einstein's field equations.

## 5. Proposition: entropic-time monotonicity

Given a partition `(B,D,∂)`, a parameter `lambda`, a normalization `Phi_0 > 0`, and a nonnegative integrable flux `Phi_∂(lambda)`, the internal time variable `tau_E` defined by:

```text
d tau_E/dlambda = Phi_∂/Phi_0
```

is monotonic.

**Proof sketch:** Since `Phi_∂ >= 0` and `Phi_0 > 0`, `d tau_E/dlambda >= 0`. Therefore `tau_E` is monotonic. If `Phi_∂ > 0` on an interval, `tau_E` strictly increases there.

## 6. Proposition: boundary-regulated clock rate

Let:

```text
Phi_∂ = g(kappa) Phi_state
```

where `Phi_state >= 0` and `g'(kappa) < 0`. Then increasing boundary opacity `kappa` decreases the entropic lapse:

```text
dN_E/dkappa = [Phi_state/Phi_0] g'(kappa) < 0
```

Plainly: raising the boundary slows the internal clock.

## 7. Fource diagnostic

Fource is defined as coherence continuity under constraint. In EBC, let:

- `C_B in [0,1]` be bright-sector coherence.
- `R_B in [0,1]` be continuity or memory preservation.
- `E_∂ in [0,1]` be meaningful exchange.
- `K >= 0` be constraint.

Define:

```text
E_∂ = 1 - exp(-Phi_∂/Phi_0)
chi(K) = K/(1+K)
F_E = C_B^alpha R_B^beta E_∂^gamma chi(K)
```

Fource is high when coherent identity survives constrained exchange. It is low when the system is chaotic, frozen, brittle, memoryless, or sealed.

## 8. Darkness Functional diagnostic

Darkness Functional measures return-path integrity.

Let `I_hidden` be information, structure, or coherence entering the dark sector. Let `I_returned` be later recoverable information, structure, or coherence returning to the bright sector.

```text
D_F = I_returned / (I_hidden + epsilon)
```

Interpretation:

- `D_F ≈ 1`: hiddenness preserves return.
- `D_F ≈ 0`: hiddenness destroys recoverability.
- `D_F > 1`: hiddenness is generative in the model sense.

## 9. Simulation architecture

EBC-SIM-001 is a classical toy universe. It models particles moving between bright and dark sectors through a boundary controlled by opacity `kappa`.

The reference barrier law is:

```text
T(kappa) = exp(-5 kappa)
```

At each step:

1. Update particle states.
2. Attempt boundary crossings.
3. Count flux.
4. Update `tau_E`.
5. Compute coherence, Fource, and Darkness Functional.
6. Render the state.

The validation expectation is qualitative: higher `kappa` should reduce transmissivity, boundary flux, entropic lapse, and final entropic time over fixed runtime.

## 10. BEC-inspired extension

The next physics-inspired layer is a one-dimensional Gross-Pitaevskii-style field model:

```text
i hbar partial_lambda psi = [-(hbar^2/2m) partial_x^2 + V(x;kappa) + g|psi|^2] psi
```

The bright and dark sectors become spatial masks separated by a tunable barrier. Entropy proxies can be computed from coarse-grained density, mode occupation, or other reduced descriptions. This extension remains mean-field and must not be presented as a full many-body calculation.

## 11. Graphene Lattice Time

Graphene and crystal growth provide a materials expression of EBC. They do not display time as an independent substance. They display time as irreversible 2D history written into structure.

In a graphene-like model:

- bright sector = crystallized lattice
- dark sector = uncrystallized reservoir/feedstock
- boundary = growth front
- trace = defects, strain, grain boundaries, birth-time map

A local cell receives a growth time:

```text
T_growth(x,y) = event time when cell crystallizes
```

A 2D sheet can then display:

- local birth time
- domain identity
- grain-boundary collisions
- defect density
- strain memory
- local coherence
- Fource field

Core law:

```text
In 2D growth, time becomes visible when a moving boundary freezes invisible possibility into irreversible structure.
```

## 12. Chronovisor evidence time

Historical reconstruction can be treated as an EBC process.

- bright sector = known evidence
- dark sector = lost context, missing records, untranslated material
- boundary exchange = discovery, translation, excavation, contradiction resolution

Define evidence time:

```text
tau_C = ∫[Phi_evidence/Phi_C0] d lambda
```

A reconstruction advances when the evidence state changes, not merely when speculation intensifies.

## 13. Garden time

The Framework Garden is also an EBC system.

- bright sector = active frameworks and written artifacts
- dark sector = dormant seeds and unprocessed insights
- boundary exchange = attention, extraction, registry assignment, cross-linking, artifact creation

Define Garden time:

```text
tau_G = ∫[Phi_attention + Phi_evidence + Phi_artifact]/Phi_G0 d lambda
```

A dormant seed is not dead. Its internal clock has slowed or stopped because exchange is low. When attention returns and produces trace, Garden time advances.

## 14. Reality interpretation

EBC does not require claiming reality is a literal computer simulation. The safer interpretation is:

> Reality is accessible through models, and every model selects a boundary, a clock variable, and a trace rule.

The four clocks should remain distinct:

1. runtime time
2. coordinate/model time
3. internal/entropic time
4. lived/observer time

The central philosophical conclusion is:

```text
Reality is not less real because it is locally incomplete. It becomes experience precisely because it is locally incomplete.
```

## 15. Validation strategy

EBC should be tested layer by layer.

Toy particle validation:

- raising `kappa` should decrease boundary flux
- `tau_E` should be monotonic when `Phi_∂ >= 0`
- sealed boundaries should stop entropic time

BEC-inspired validation:

- split-step solver should conserve norm within tolerance
- barrier sweeps should alter bright/dark exchange
- entropy proxies must be sensitivity-tested

Graphene validation:

- growth-time maps should reproduce qualitative relations among flux, nucleation density, domain size, grain-boundary length, and defect density
- kinetic Monte Carlo event-time should follow `Delta t = -ln(u)/R_total`

## 16. Conclusion

EBC defines a universe model in which internal time emerges from boundary-conditioned incompleteness. A total system is partitioned into a bright sector, a dark sector, and a boundary. The bright sector has only a reduced state. Entropy and trace appear as the local cost of incomplete access. Boundary flux generates an internal entropic time variable. This time can speed up, slow down, or stop relative to an external parameter depending on trace-bearing exchange.

Final law:

```text
A universe becomes temporal when hidden coherence crosses a boundary and returns as trace.
```
