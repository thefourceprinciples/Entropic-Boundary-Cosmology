## Core model

Let a total system be partitioned as:

```text
U = B ∪ D ∪ ∂
```

where:

- `B` is the bright sector: accessible, measurable, recorded.
- `D` is the dark sector: inaccessible, ignored, traced out, unresolved, or hidden relative to `B`.
- `∂` is the boundary/interface through which exchange may occur.

For a quantum model:

```text
rho_B = Tr_D(rho_U)
S_B = -k_B Tr(rho_B log rho_B)
```

Define boundary flux:

```text
Phi_∂ >= 0
```

and internal entropic time:

```text
d tau_E / d lambda = Phi_∂ / Phi_0
```

If `Phi_∂ > 0`, internal time advances. If `Phi_∂ = 0`, internal entropic time stops relative to the chosen partition.
