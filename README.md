# Entropic Boundary Cosmology

[![EBC-SIM-001 Tests](https://github.com/thefourceprinciples/Entropic-Boundary-Cosmology/actions/workflows/ebc-sim-001-tests.yml/badge.svg)](https://github.com/thefourceprinciples/Entropic-Boundary-Cosmology/actions/workflows/ebc-sim-001-tests.yml)

**Entropic Boundary Cosmology (EBC)** is a relational-time and simulation framework for modeling how internal clocks can emerge from entropy-producing exchange across boundaries between accessible and inaccessible sectors of a closed or effectively closed system.

> The clock is born at the veil.

This repository starts with **EBC-SIM-001 — Bright/Dark Entropic Clock**, a classical toy simulator and validation scaffold. It also includes the first manuscript draft for EBC as a preprint-style body of work.

## Current package

- `simulations/ebc-sim-001/` — browser and Python toy simulator.
- `manuscripts/EBC_Manuscript_v0_1.md` — first full manuscript draft.
- `docs/` — framework notes, literature map, validation plan, and next planks.

## Claim boundary

This project does **not** claim to replace general relativity, quantum field theory, standard cosmology, or thermodynamics. EBC is currently a formal/simulation framework for comparing internal time variables: entropy time, model time, growth time, evidence time, and archive time.

`Fource` and `Darkness Functional` are framework-specific diagnostics, not established physical observables.

A universe becomes temporal when hidden coherence crosses a boundary and returns as trace.
